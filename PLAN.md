# PLAN.md - Token Lab

План MVP на 5 кроків. Правила - у `CLAUDE.md`. Каркас (папки, `.gitignore`, порожній `index.html`) уже є.

Робимо в гілці `feat/token-lab-mvp`, коміт після кожного кроку (Conventional Commits). Пуш і PR - тільки після «ок».

Відкрите питання: шкала. У цьому плані вона 100…1000 (10 кроків), а в `CLAUDE.md` написано 50…950. Треба вирішити і оновити `CLAUDE.md`.

## 1. Математика кольору - `public/color.js` + `tests/color.test.js`
- Парсинг і валідація hex (`#RGB`, `#RRGGBB`, з `#` і без).
- hex ↔ OKLCH (через лінійний sRGB), повернення в гамут sRGB зменшенням хроми.
- Шкала 100…1000 для brand: фіксовані рівні світлоти, відтінок з бренд-кольору.
- Шкала neutral: той самий відтінок, хрома майже нуль.
- Контраст WCAG 2.x (відносна яскравість, ratio) і рівень: AAA / AA / AA Large / Fail.
- Вибір on-accent: білий або темний, у кого контраст більший.
- `package.json` з одним рядком `"type": "module"`, без залежностей, щоб `node --test` імпортував ES-модулі.
- Готово, коли: `node --test` зелений; для `#FACC15` on-accent темний, для `#4F46E5` - білий.

## 2. Токени і експорт - `public/tokens.js`
- Семантичні токени для світлої і темної теми: bg, surface, text, text-muted, border, accent, accent-hover, on-accent, danger, success.
- Кожен токен посилається на крок шкали (primitive), а не на довільний hex.
- Експорт: CSS variables, Tailwind v4 `@theme`, `tokens.json` (primitives → light / dark).
- Готово, коли: експорт для `#4F46E5` і `#FACC15` дає валідний CSS / JSON.

## 3. Інтерфейс - `public/index.html`, `styles.css`, `app.js`
- Дизайн з `design/` (скрін або Figma). Geist + Geist Mono, нейтральний фон, лінії 1px, сітка, без градієнтів.
- Поле hex з помилкою під ним, свотчі обох шкал, таблиця токенів.
- Живе прев'ю (кнопка, картка, інпут) у світлій і темній темі з бейджами контрасту.
- Блок експорту з табами і кнопками «Копіювати», тост «Скопійовано».
- Усі кольори UI - змінні в `:root`. Фокус видно з клавіатури. Адаптив від 360px, одна колонка на мобільному.
- Готово, коли: у браузері все працює для `#4F46E5` і `#FACC15`, на 360px немає горизонтального скролу.

## 4. «Поділитися» - `functions/`, `schema.sql`, `wrangler.toml`
- `schema.sql`: таблиця `palettes` (id, hex, created_at).
- `POST /api/palettes` - зберегти, повернути `{ id, url }`. Короткий id на 6 символів.
- `GET /api/palettes/:id` - віддати палітру, 404 якщо немає.
- `/p/:id` - віддає `index.html`, клієнт підтягує палітру.
- Локально: `npx wrangler d1 execute token-lab --local --file=schema.sql`, потім `npx wrangler pages dev`.
- Готово, коли: посилання з кнопки відкриває ту саму палітру в новій вкладці.
